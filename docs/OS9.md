# Native Microware OS-9 classic RBF

Branch `os-9` starts at develop-4.1x commit
8101890d2965c11d801dd64436ddf053262d727e, retaining QNX6 and merged QNX4 support.
The reference reader is Gerd1986/qnxprobe at
e7bf24aef2ee90a1583b9479d3e16c05346d4f4c, Os9RbfWalker and _os9_probe.
Its MIT license is in tsk/fs/os9_LICENSE.txt.

RBF has no fixed magic. Detection validates the big-endian 24-bit volume and
root LSN fields, allocation-map geometry, the directory FD, and root dot/dotdot
records. It tests sector sizes 128, 256, 512, 1024, 2048 and 4096. Volume offsets
use the standard TSK -o interface. Inodes are FD LSNs, and data runs are physical
sector segments. Classic FD segment tables are bounded to 48 slots / 256 bytes
(or the smaller physical sector), without interpreting padding as more segments.

Directories have 29-byte high-bit-terminated names and a 24-bit FD LSN. File
segments are followed exactly; malformed extents and short coverage are rejected.
Empty files, nested directories, hardlinks, inode walking, FD owner and link count
are supported. The owner read/write/execute and public read/write/execute bits
map to POSIX owner/other permissions; no separate group permissions are invented.
The shareable attribute is not repurposed as a POSIX permission bit.

The MSB-first allocation bitmap maps clusters of DD.BIT sectors. Set bits mean
allocated; blkls exports free sectors, respecting whole-cluster allocation and
avoiding live file/metadata overlap. The classic bitmap starts at LSN 1. A valid
OS-9/68K Cruz extended header may relocate it with DD.MAPLSN. Metadata sectors
include the volume descriptor, bitmap, active FDs and directory segments.

FD modification dates carry year-since-1900/month/day/hour/minute. Creation dates
carry only year/month/day and are represented at midnight. Fields have no timezone;
conversion follows the qnxprobe reference's UTC interpretation. Access and inode
change times are not stored in these records and are not invented. Invalid dates
remain unknown. This driver targets classic Microware RBF; OS-9000/newer unrelated
formats, deleted filenames and orphan FD scanning are not implemented.

```
fsstat image.img
fls -r -p image.img
icat image.img FD_LSN > extracted.bin
istat image.img FD_LSN
ils -a image.img
blkls image.img > unallocated.bin
fls -f os9-rbf -o 2048 disk.img
```

Tests compare 414 synthetic payloads with independently generated bytes and the
user's qnxprobe reader across all sector sizes and cluster sizes 1/2/4. They cover
high-bit names, fragmented segments, empty files, aliases/hardlinks, nested and
multi-sector directories, metadata, offsets, relocated maps and invalid structures.
A historical disk, c3/prep19/ghcprep.dsk from nitros9project/toolshed commit
9b8ac74f3c3f4afa039c1dbf94fd64e3a76c2928, supplies additional independent input;
its whole live tree and contents must agree with the reference reader. Toolshed's
bitmap implementation was consulted to check bit order, without copying its code.
Release binaries run these regressions on Linux and packaged Windows executables.
